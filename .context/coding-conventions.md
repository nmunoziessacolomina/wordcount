# Convenciones de código

## Idioma

- Todos los identificadores del código deben estar en **inglés**.
- Los nombres de archivos deben estar en **inglés**.
- Los comentarios y la documentación dentro del código deben estar en **inglés**.

## Principios

- Mantener el código simple y legible.
- Seguir las convenciones existentes en el proyecto.
- Evitar complejidad innecesaria.
- No realizar cambios de estilo que no sean necesarios para la feature.
